# NBAIS O'Level Integration — V17

NBAIS is a controlled O'Level examination authority in the admissions reference catalogue.
The applicant-facing system selects an authority and then an authority-owned examination type; standardized values are not free text.

Supported NBAIS reference types:
- SAISSCE — Senior Arabic and Islamic Secondary School Certificate Examination
- NBAIS Science Examination
- Legacy SSCE record retained inactive for compatibility

Tahfeez is not automatically classified as an O'Level equivalency. It is a distinct NBAIS examination/certification stream and should only affect admission eligibility when the institution's approved policy explicitly recognizes it.

Data flow: Applicant → Examination Authority → Examination Type → Subject → Grade → Sitting → Verification status.
