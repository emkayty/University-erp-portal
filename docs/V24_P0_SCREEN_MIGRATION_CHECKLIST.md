# V24 P0 Screen Migration Checklist

For each P0 route, the implementation should use the V23 AppShell and V24 interaction primitives where applicable.

## Dashboard
- [ ] Role-aware title/context
- [ ] Metrics limited to actionable/meaningful measures
- [ ] Needs-attention queue above low-value activity
- [ ] Quick actions
- [ ] Loading/empty/error states
- [ ] Mobile preserves priority

## Admissions
- [ ] Applicant identity/status above the fold
- [ ] Workflow progress visible
- [ ] Qualification data structured
- [ ] Documents grouped by requirement/status
- [ ] Decision controls permission-protected
- [ ] Timeline/audit visible to authorized staff
- [ ] Applicant-facing language is empathetic and unambiguous

## Student
- [ ] Identity/programme/level/session/semester
- [ ] Academic standing
- [ ] Registration and results
- [ ] Financial state
- [ ] Support/history
- [ ] Sensitive information minimized

## Course Registration
- [ ] Session/semester locked into context
- [ ] Course search/filter
- [ ] Prerequisite/conflict explanations
- [ ] Credit limit indicator
- [ ] Selected-course summary
- [ ] Confirmation/receipt
- [ ] Mobile course cards

## Exams & Results
- [ ] Assessment context
- [ ] Configured grading scale shown
- [ ] Draft/submitted/moderated/published/locked status
- [ ] Inline validation
- [ ] Bulk upload preview and row-level errors
- [ ] Permission-aware publication
- [ ] Audit/history

## Finance
- [ ] Invoice and amount
- [ ] Payment state
- [ ] Balance
- [ ] Receipt
- [ ] Failed/pending explanation
- [ ] Reconciliation exceptions
- [ ] Sensitive payment details minimized

## Global
- [ ] 320/375/390/430/768/1024/1280/1440px QA
- [ ] Keyboard navigation
- [ ] Focus visible
- [ ] Screen-reader labels
- [ ] No hover-only critical actions
- [ ] No color-only meaning
- [ ] No destructive action without confirmation
