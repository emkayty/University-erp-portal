# V28 — Institutional UI/UX Consolidation

V28 consolidates the ERP around one authoritative institutional design language.

Principles:
- clarity before decoration
- task completion before dashboard vanity
- role-specific experiences
- progressive disclosure
- structured data over unnecessary free text
- safe, recoverable actions
- accessible by default
- mobile task completion
- performance-conscious surfaces
- security-aware presentation
- calm, distinctive institutional polish

Legacy visual systems are marked for migration/removal rather than extended.
