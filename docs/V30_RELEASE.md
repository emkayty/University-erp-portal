# V30 — Screen-Level UX Migration & QA

V30 moves from design-system definition toward real application shell and screen-level quality gates.

The objective is not more decoration. It is consistent execution:
- domain navigation
- responsive shell
- role-aware context
- predictable states
- safe actions
- accessible interaction
- performance-conscious presentation

Backend authorization remains the source of truth; frontend visibility is only a UX layer.
