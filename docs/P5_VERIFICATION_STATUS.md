## What is NOT claimed

This archive-only pass does not claim that every dynamic test has passed. A real PASS requires installing dependencies, connecting a controlled PostgreSQL/Redis test environment, running migrations, executing unit/integration/E2E tests and capturing evidence.

This distinction is intentional: declaring an ERP "certified" without executing the evidence would be misleading, particularly for examinations, grades, finance, admissions and authorization.

## Standards note

NUC accreditation and Minimum Academic Standards are institutional/regulatory matters, not software certifications. ISO 21001:2025 is a management-system standard; the ERP can be designed to support conformity but cannot make the university certified merely by implementing features.
